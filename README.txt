1. Put your files in media/ (resume.pdf, lor.pdf, mca-degree.pdf, bca-degree.pdf, cloud-computing.pdf, sih.pdf) or change the paths in data.js.
2. Open index.html in a browser.
3. Edit data.js only; refresh to see changes. Add certifications by copying one line in `certifications`.
4. Project cards: set featured:true for the big cards; the rest appear under "Show all projects". Add image:"media/shot.png" for a screenshot.
5. To go online upload the whole folder (including media/) to Vercel, Netlify or GitHub Pages.
